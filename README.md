## 📱 How to Use | راهنمای استفاده

### English
1. Copy any of the subscription URLs above.
2. Open your client (e.g. **v2rayNG**, **V2Box**, **Streisand**, **sing-box**, **NekoBox**, **v2rayN**).
3. Navigate to **Subscription Group / Settings** -> **Add Subscription**.
4. Paste the URL and save.
5. Tap **Update Subscription** to fetch the latest active nodes.

### فارسی
۱. یکی از لینک‌های بالا را کپی کنید.
۲. برنامه کلاینت خود را باز کنید (مانند **v2rayNG**، **V2Box**، **Streisand**، **sing-box** یا **NekoBox**).
۳. به بخش تنظیمات اشتراک‌ها (Subscription Group / Settings) رفته و گزینه افزودن (Add) را انتخاب کنید.
۴. لینک کپی‌شده را در فیلد مربوطه قرار دهید و ذخیره کنید.
۵. گزینه **Update Subscription** (بروزرسانی اشتراک) را بزنید تا لیست سرورهای فعال دریافت شود.
